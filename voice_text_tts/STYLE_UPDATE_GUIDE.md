# 样式更新说明

## 更新时间
2026-01-23

## 更新内容

### 样式统一
✅ **ASR按钮样式已统一** - 与"生成语音"按钮保持一致的设计风格

### 具体修改

#### 1. 移除表情符号
**之前：**
- 按钮文字：`🎤 提取音频文字`
- 状态消息：包含 ✅ ❌ ⚠️ 💡 等表情符号

**现在：**
- 按钮文字：`提取音频文字`
- 状态消息：纯文字，无表情符号

#### 2. 按钮样式统一
**之前：**
```python
asr_btn = gr.Button(
    "🎤 提取音频文字",
    variant="secondary",
    size="sm",
    elem_classes=["asr-button"]  # 自定义样式
)
```

**现在：**
```python
asr_btn = gr.Button(
    "提取音频文字",
    variant="secondary",
    size="sm",
    elem_classes=["generate-button-full-width"]  # 使用统一样式
)
```

#### 3. 删除自定义CSS
移除了以下自定义样式：
- `.asr-button` - ASR按钮渐变样式
- `.asr-button:hover` - 悬停效果
- `.asr-button:active` - 点击效果

**保留的样式：**
- `.asr-status` - ASR状态提示样式（保持与其他提示一致）
- `.generate-button-full-width` - 统一的按钮样式类

#### 样式对比
| 按钮名称 | 样式类型 | 颜色主题 |
|---------|---------|---------|
| 提取音频文字 | secondary | 灰色调 |
| 生成语音 | primary | 深蓝色调 (#091a31) |

```css

.generate-button-full-width {
    background-color: #091a31;
    color: #ffffff;
    padding: 14px 24px;
}

/* 次要按钮（提取音频文字） */
.gr-button-secondary {
    background-color: #ffffff;
    color: #0f3460;
    border: 1px solid #d0d3d9;
}
```
