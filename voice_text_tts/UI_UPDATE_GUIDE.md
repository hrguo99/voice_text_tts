# 界面优化更新说明

## 更新时间
2026-01-23

## 更新内容

### 新增功能
✅ **ASR提取按钮** - 添加了"🎤 提取音频文字"按钮，用户可以主动选择是否使用ASR识别

### 优化改进

#### 1. 更灵活的交互方式
**之前：**
- 参考音频文本留空时自动调用ASR识别
- 用户无法选择识别时机
- 识别结果不可修改

**现在：**
- 用户可以选择手动输入文字或点击按钮提取
- 完全掌控识别时机
- 识别后可以查看并修改结果

#### 2. 新增UI元素

**ASR提取按钮**
- 🎤 精美的渐变色按钮设计
- 紫色渐变：#667eea → #764ba2
- 悬停效果和点击反馈
- 全宽设计，易于点击

**ASR状态提示**
- 识别成功：显示结果摘要
- 识别失败：显示详细错误信息
- 友好的emoji图标
- 清晰的建议和提示

#### 3. 更新使用说明

**新的使用方式：**
- **方式一（手动输入）**: 直接在文本框输入文字内容
- **方式二（ASR提取）**: 上传/录制音频后，点击按钮自动识别

### 用户使用流程

#### 方式一：手动输入
```
1. 上传/录制参考音频
2. 在"参考音频文本"框手动输入文字
3. 输入要合成的文本
4. 点击"生成语音"
```

#### 方式二：ASR提取
```
1. 上传/录制参考音频
2. 点击"🎤 提取音频文字"按钮
3. 等待识别完成
4. 查看/修改识别结果
5. 输入要合成的文本
6. 点击"生成语音"
```
